💜 Acerca de TareaFácil y ayuda

Un espacio creado para ayudarte a organizar tus actividades escolares.

¿Para qué sirve TareaFácil?

Te permite registrar tus tareas, indicar el curso y la fecha de entrega, elegir una prioridad, escribir detalles y marcar actividades como completadas.

¿Cómo agrego o edito una tarea?

Usa el formulario “Agregar una tarea”. Para modificar una actividad, pulsa el lápiz; para eliminarla, pulsa la papelera.

¿Dónde se guardan mis datos?

Por ahora, las tareas, el horario y las preferencias se guardan localmente en este navegador. Si borras los datos del navegador o cambias de dispositivo, podrían no estar disponibles. No ingreses información privada.

¿TareaFácil cuesta dinero?

Estas funciones no requieren pagos ni suscripciones. La página todavía no está publicada en un dominio propio.
